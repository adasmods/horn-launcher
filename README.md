# horn-launcher
Private, non-commercial Minecraft: Java Edition launcher for friends. Microsoft sign-in, one-click install of the HORN Client modpack (1.21.11 + Fabric), Modrinth mods &amp; shaders. Premium accounts only, no cheats.



HORN Launcher
A small, non-commercial launcher for Minecraft: Java Edition, made for a private group of friends. It installs and starts the HORN Client modpack (Minecraft 1.21.11 + Fabric) with one click.

HORN Launcher is not an official Minecraft product. It is not approved by or associated with Mojang or Microsoft.

Features
Microsoft account sign-in. Uses the official Microsoft login page in your browser, or a device code. Then Xbox Live → XSTS → Minecraft services. Game ownership is verified.
Automatic installation. Downloads the official game files, libraries, assets and Java runtime from Mojang's servers. It also downloads the Fabric loader from FabricMC. Every file is checked with SHA-1.
HORN Client modpack. Installs mods and resource packs from Modrinth and keeps them up to date.
Modrinth browser. Search and install mods, shaders and resource packs.
Festive, modern UI with animations.
Privacy and security
Sign-in tokens are stored only on your computer, encrypted with Windows DPAPI.
Tokens are sent only to Microsoft / Xbox / Minecraft services. They are never shared, logged or uploaded anywhere else.
No telemetry and no ads.
What it does NOT do
No offline or cracked accounts. Every player must own Minecraft: Java Edition.
No cheats. The HORN Client mod only contains legit features: HUD, cosmetics visible to the user only, performance options and quality-of-life tools.
No paid content. The launcher does not sell or monetize anything.
Requirements
Windows 10/11 (x64)
A Microsoft account that owns Minecraft: Java Edition
About 1 GB of free disk space for the first installation
